# GameEngine — Tank Arena

Учебный игровой проект на C++17 и OpenGL 4.6: танковый бой на небольшой арене. Проект включает собственные классы рендеринга, загрузчик ресурсов и игровую логику без готового игрового движка.

## Возможности

- Карта 30×20 клеток со стенами и разрушаемыми ящиками.
- Игрок управляет танком размером 24×24 игровых единицы.
- Пять вражеских танков ищут путь вокруг препятствий и стреляют при прямой видимости игрока.
- Снаряды уничтожают ящики и вражеские танки; стены непробиваемы.
- У игрока 3 единицы брони. После попадания действует короткая защита от повторного урона.
- Счётчик противников, табло победы после уничтожения всех пяти танков и экран поражения.
- Перезапуск боя восстанавливает карту, броню и противников.

## Запуск готовой игры

1. Открой [Releases](https://github.com/kek1v/GameEngine/releases).
2. Скачай архив `GameEngine-0.1.0-windows-x64.zip`, когда он будет опубликован.
3. Распакуй архив целиком и запусти `GameEngine.exe`.

Папка `res` должна находиться рядом с исполняемым файлом. Не запускай игру прямо из ZIP.

Требования: **Windows 10/11 x64**, видеокарта и драйвер с поддержкой **OpenGL 4.6**. Для архива, собранного скриптом релиза, не нужны CMake, Visual Studio и отдельная установка среды Visual C++: она связана статически. Звук, мультиплеер и сохранение прогресса пока не реализованы.

## Сборка из исходников

Проверенная среда: Windows x64, Visual Studio Build Tools 2022 с компонентами C++ и Windows SDK, CMake 3.29 или новее. Сторонние библиотеки уже включены в `external`.

```powershell
git clone https://github.com/kek1v/GameEngine.git
cd GameEngine
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel 1 -- /nr:false
ctest --test-dir build -C Release --output-on-failure
& .\build\bin\Release\GameEngine.exe
```

CMake копирует ресурсы к исполняемому файлу. Если команда `cmake` не найдена после установки, открой новый терминал или добавь папку CMake в PATH.

### Архив для релиза

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-release.ps1 -Version 0.1.0
```

Скрипт выполняет отдельную Release-сборку со статической средой C++, запускает тесты и создаёт ZIP и файл SHA-256 в `build/releases`. В архив входят игра, ресурсы, README и уведомления сторонних библиотек; исходники и отладочные файлы не включаются.

## Структура

- `src/Game/World.*` — карта, столкновения, снаряды, AI и состояние боя; не зависит от OpenGL.
- `src/Game/game.*` — ввод, связь игровой логики с отрисовкой.
- `src/Game/Tank.*` — отображение танка игрока.
- `src/Game/Scoreboard.*` — табло и счётчики; текст растеризуется через Windows GDI.
- `src/Renderer` — шейдеры, текстуры, спрайты и GPU-буферы.
- `src/Resources` — загрузка JSON, изображений и ресурсов.
- `res` — шейдеры, текстуры и описание ресурсов.
- `tests/WorldTests.cpp` — проверки столкновений, AI, попаданий, победы, поражения и перезапуска.

## Зависимости и ограничения

GLFW создаёт окно и обрабатывает ввод; GLAD загружает OpenGL; GLM используется для математики; RapidJSON читает ресурсы; stb_image загружает изображения. Условия использования сторонних компонентов находятся в их исходниках и каталоге `licenses` релизного архива.

Текущая сборка рассчитана на Windows: модуль табло использует GDI. Это учебный проект; AI простой, враги перемещаются по четырём направлениям. Общая лицензия проекта пока не объявлена.
